## 👋 About This Project

This is the personal developer portfolio of **Faizan Ali** — an MCA student at MJPRU (2025–2027) focused on **Python Backend Development with AI Automation** and modern web development.

Engineered from scratch with pure semantic HTML5, modern CSS3, and vanilla JavaScript (zero heavy frameworks), the portfolio combines a **dark glassmorphism aesthetic** with an energetic **red accent design system** (`#e63946`). It is fast, accessible, and structured to present backend capabilities, software engineering projects, and internship experience to recruiters and engineering teams.

## ✨ Key Features

| Feature | Details |
|---|---|
| 🎨 **Design System** | Dark theme, multi-layer glassmorphism, glowing ambient blobs, and custom red accent palette |

| 🔒 **Protected Resume** | Native PDF download combined with an accessible dialog for requesting the encryption password |

| 📬 **Validated Contact** | Form validation with integrated EmailJS v4 client submission and direct mail fallback |
| 📱 **Fully Responsive** | Optimized layouts across mobile (<480px), tablet (768px), and desktop viewports |
| ♿ **Accessibility (a11y)** | Skip link, ARIA dialogs/labels, keyboard navigation support, and reduced-motion respect |
| 🔍 **SEO & Social Graph** | Custom JSON-LD schema, canonical URLs, Twitter cards, and dedicated 1200x630 Open Graph preview image |

## 🚀 Local Setup

```bash
# Clone the repository
git clone https://github.com/FaiizanAly/dev.faizan.git

# Navigate into the project folder
cd dev.faizan

# Launch using any local server (no build step required):
npx serve .

# Or with Python:
python -m http.server 8080
```

> Once started, navigate to [http://localhost:8080](http://localhost:8080) in your web browser.
