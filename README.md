## 👤 About the Project

This portfolio showcases the academic journey, technical credentials, hands-on projects, and professional internships of **Faizan Ali** — an MCA Student (2025–2027), Aspiring Java Developer, Web Developer, and Generative AI enthusiast.

### 💡 Core Design Philosophy
- **Pure Web Fundamentals:** Built with 100% semantic HTML5, modern CSS3, and vanilla ES6+ JavaScript. No React, Vue, Tailwind, Bootstrap, or heavy third-party runtimes.
- **Instant Load Time:** Zero build step overhead, zero bundle lag, and lightning-fast First Contentful Paint (FCP).
- **Dark Glassmorphism Identity:** Deep canvas surfaces (`#08080f`), translucent blurred frosted-glass cards, and high-energy crimson accents (`#e63946`).

## ✨ Key Features

| Category | Feature | Implementation Details |
|---|---|---|
| 🎨 **Design System** | Dark Glassmorphism | Custom CSS properties, `backdrop-filter: blur(20px)`, subtle glow shadows, and dynamic hover cards. |

| 📱 **Navigation** | Responsive Drawer | Desktop sticky navbar with smooth-scroll offset calculation and mobile off-canvas drawer with keyboard ESC exit. |
| 📬 **Contact Form** | EmailJS v4 Integration | Client-side validation, regex pattern checks, and direct async email dispatch with user feedback states. |
| 📊 **GitHub Activity** | Live Stat Widgets | Integrated dynamic SVGs for contributions, language statistics, and commit streaks with automatic error fallbacks. |
| 📄 **Curriculum Vitae** | Instant Download | Hosted PDF resume served via Vercel edge header forcing clean attachment downloads. |
| ♿ **Accessibility** | Inclusive UX | Screen-reader skip link (`#main`), focus-visible indicators, ARIA labels, and `prefers-reduced-motion` compliance. |

## 🗂️ Website Sections

The portfolio is structured as a unified single-page application with 8 targetable sections:

1. **Hero (`#hero`)** — Brand name, interactive typewriter subtitle, availability pill, CV download button, and social links.

6. **Certifications (`#certifications`)** — Verified industry credential badges from AWS, Tata Group, Power BI, and Microsoft/LinkedIn.
7. **GitHub Activity (`#github`)** — Live open-source metrics, language distribution, and contribution streak counter.
8. **Contact (`#contact`)** — Direct contact information card alongside an interactive, validated EmailJS messaging form.

## 🚀 Run Locally

Because the project is built purely with native web standards, it requires **no Node.js packages, build steps, or installations**.

### Step 1: Clone the repository
```bash
git clone https://github.com/FaiizanAly/dev.faizan.git
cd dev.faizan
```

### Step 2: Open in your browser
You can open `index.html` directly in any web browser, or serve it through a local HTTP server:

#### Option A: Using Python 3 (Recommended)
```bash
python -m http.server 8080
```
Then visit: `http://localhost:8080`

#### Option B: Using Node Static Server (if available)
```bash
npx serve .
```

## ⚙️ Customization Guide

If you are using this repository as a template for your own developer portfolio:

1. **Personal Information & Bio:** Update your name, title, bio, and social links in `index.html` (under `#hero` and `#about`).
2. **Skills Toolkit:** Customize the categories and skill pills in `index.html` (under `#skills`).
3. **Projects:** Add or edit project cards in `index.html` (under `#projects`). Update repository and live demo URLs.
4. **Experience & Education:** Edit the timeline entries in `index.html` (under `#experience`).
5. **Color Theme & Design Tokens:** Modify CSS custom properties in `:root` inside `styles.css`:
   ```css
   --red: #e63946;         /* Primary brand accent */
   --bg-dark: #08080f;     /* Background canvas */
   --card-bg: rgba(255, 255, 255, 0.04);
   ```
6. **Contact Form Setup:** Register at [EmailJS](https://www.emailjs.com/) and replace the keys in `script.js`:
   ```javascript
   const EMAILJS_PUBLIC_KEY  = 'YOUR_PUBLIC_KEY';
   const EMAILJS_SERVICE_ID  = 'YOUR_SERVICE_ID';
   const EMAILJS_TEMPLATE_ID = 'YOUR_TEMPLATE_ID';
   ```
7. **Curriculum Vitae:** Replace `resume/resume.pdf` with your own PDF document.

## 🌐 Deployment

The live site is hosted on **Vercel** with automatic continuous deployment linked to the `main` branch.

- **Production URL:** [https://dev-faizan.vercel.app/](https://dev-faizan.vercel.app/)
- **Vercel Configuration (`vercel.json`):**
  - Enforces HTTPS and clean URLs (`cleanUrls: true`).
  - Implements custom security headers: `X-Content-Type-Options: nosniff`, `X-Frame-Options: DENY`, `X-XSS-Protection`, and `Referrer-Policy`.
  - Configures dedicated caching headers for stylesheets, scripts, and PDF attachments.

## 🔒 Accessibility, SEO & Security

- **Accessibility (a11y):**
  - Includes a `#main` skip link for screen readers and keyboard navigation.
  - Visible focus indicators (`:focus-visible`) styled in high-contrast red.
  - Full `@media (prefers-reduced-motion: reduce)` support that disables background animations and transitions.
- **Search Engine Optimization (SEO):**
  - Embedded Schema.org `Person` JSON-LD structured data.
  - Comprehensive OpenGraph and Twitter card metadata for rich link sharing.
  - Dedicated `sitemap.xml` and `robots.txt` configuration.
- **Security:**
  - Strict external link security using `rel="noopener noreferrer"`.
  - Content sniffing and framing protections enabled at the Vercel edge.
