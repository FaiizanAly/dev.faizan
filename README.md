## 👋 About This Project

This is my **personal developer portfolio** — designed from scratch with zero frameworks or UI libraries.  
Built to be fast, accessible, and visually sharp with a **dark glassmorphism aesthetic** and **premium red accents**.

No React. No Tailwind. No Bootstrap. Just clean vanilla code. 🔥

---

## ✨ Features

| Feature | Details |
|---------|---------|
| 🎨 **Design** | Dark theme · Glass morphism · Red accent system |
| ✍️ **Typewriter** | Animated role cycling in the hero section |
| 📜 **Scroll Reveal** | Smooth IntersectionObserver-based reveal animations |
| 📊 **GitHub Stats** | Live GitHub stats, top languages & streak cards |
| 📬 **Contact Form** | EmailJS-powered contact form with validation |
| 📱 **Responsive** | Mobile · Tablet · Desktop — all breakpoints covered |
| ♿ **Accessible** | Skip link · ARIA labels · Keyboard nav · Reduced motion |
| ⚡ **Performance** | rAF-throttled scroll · Passive listeners · Zero layout shift |
| 🔒 **Secure** | Vercel security headers (CSP, X-Frame, XSS protection) |
| 🔍 **SEO Ready** | JSON-LD schema · OpenGraph · Twitter cards · Sitemap |

## 🚀 Run Locally

```bash
# Clone the repo
git clone https://github.com/FaiizanAly/dev.faizan.git

# Open in browser — no build step needed!
# Just open index.html directly, or use a local server:
npx serve .

# Or with Python:
python -m http.server 8080
```

> Then open [http://localhost:8080](http://localhost:8080)
